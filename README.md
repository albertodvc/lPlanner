# lPlanner

A utility to plan LP sides content, served as a single static GitHub Pages site.

## Publish with GitHub Pages

The site is plain HTML and CSS in the repository root; there is no build step.

1. In the repository settings, open **Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the branch containing these files and the `/(root)` folder, then save.

GitHub Pages serves `index.html` directly from that branch.
